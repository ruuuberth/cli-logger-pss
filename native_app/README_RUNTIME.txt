PSS Logger Native (Portable Runtime)

This package is intended to run without local .env setup.

Included:
- pss-logger-native executable
- third_party/mitmproxy runtime
- THIRD_PARTY_NOTICES.txt

Quick start:
1. Extract the ZIP.
2. Run the executable from this folder.
3. Configure game proxy to 127.0.0.1:8081.

Notes:
- You can still override settings via environment variables.
- If capture is unavailable, use the in-app status message for diagnostics.
